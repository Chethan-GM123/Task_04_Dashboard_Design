# 📊 Task 04 – Interactive Dashboard Design

## Overview
Developed an interactive **Power BI dashboard** to analyze sales performance using the Superstore dataset.

## Tools
- Power BI
- Microsoft Excel

## Dashboard Highlights
- KPI Cards (Sales, Profit, Orders, Customers)
- Interactive Slicers
- Sales Trend Analysis
- Regional Performance
- Category & Segment Analysis
- Discount vs Profit Analysis

## Key Insights
- Technology achieved the highest sales.
- West region generated the strongest performance.
- Consumer segment contributed the most sales.
- High discounts negatively impacted profit.
